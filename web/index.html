初始化连接：绑定你的 Kaggle 账号与 API Key

连接后即可直接在 Kaggle 免费 T4 GPU 上运行 OmniVoice，无需手动建 Notebook 或上传模型权重。

1 注册并查看 Kaggle 用户名

  1. 打开 kaggle.com，点击右上角 Register（可用 Google 账号或邮箱注册）。
  2. 登录后点击右上角头像 → Your Profile，查看浏览器地址栏：https://www.kaggle.com/<用户名>。
  3. 把网址最后那段 <用户名> 填到右侧（注意不是显示昵称，例如 demon820308）。

2 验证手机号（开启 GPU 与联网必需）

  1. 点击右上角头像 → Settings，找到 Phone verification 栏目。
  2. 选择国家区号（如中国大陆选 +86），输入手机号并填写短信验证码。
  3. 说明：未完成手机验证的账号无法调用免费 T4 GPU（每周 30 小时）和内核联网下载模型。

3 创建 KGAT_ API Key

  1. 在 Settings 页面向下滚动到 API 区域。
  2. 点击 Generate New Token（或 Create New Token），复制生成的新版 Token（必须以 KGAT_ 开头）。
  3. 提示：不要填写旧版 kaggle.json 内容；如果以后本周 30h 额度用完，可在右上角「账号设置」添加另一个 Kaggle 账号随时切换。
